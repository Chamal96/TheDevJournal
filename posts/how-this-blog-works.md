This blog is a folder of files, not a rented platform.

## Writing

Each post is a Markdown file in `posts/`. The homepage reads `posts/index.json` to know what to list. When a post is ready, it goes into that list and becomes public.

## Reading

Visitors open the site and click a title. The post page loads the Markdown file and renders it. No account is required.

## Publishing for free

The site is static HTML, CSS, and JavaScript. That means GitHub Pages can host it at no cost. Push the folder to a GitHub repository, turn on Pages, and the public URL is live.

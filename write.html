GitHub Pages cannot save files. One free Firebase project lets this page publish without git.

  1. Create a project at Firebase Console.
  2. Enable Authentication → Google.
  3. Create a Firestore database, then paste the rules from firestore.rules.
  4. Authentication → Settings → Authorized domains: add chamal96.github.io.
  5. Project settings → Your apps → Web app. Copy the keys into config.js under firebase.
